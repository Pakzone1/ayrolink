# AyroLink

AyroLink by Ayroflow is a real-time voice agent for WhatsApp calls and messages. It carries conversation context across calls, messages, images, and voice notes.

Review transcripts and call summaries in one workspace, take over a conversation when needed, and follow up with opt-in callbacks. Approved users can also connect compatible MCP clients to initiate calls and review outcomes.
